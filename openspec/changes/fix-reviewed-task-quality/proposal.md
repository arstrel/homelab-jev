# Proposal

## Why

The first live preview confused promotional/conditional calls to action with obligations and produced a generic click-to-review title. The underlying finite-choice adapter needs literal eligibility criteria and source context before another useful capture can be attempted.

## What Changes

- Require an independent outstanding-obligation judgment before proposing a selected sentence.
- Give choices direct quoted source/project descriptions instead of opaque reference-only criteria.
- Use the originating subject to turn generic review links into meaningful source-based titles; reject other context-free link prompts.
- Sample stored conversations by message recency rather than retrieval time.
- **BREAKING**: require new v2 review files; preserve the existing stable creation identity and task links.

## Capabilities

### New Capabilities

- `reviewed-email-tasks`: refine the same capability in the earlier unarchived change; no canonical capability has been published yet.

### Modified Capabilities

None in the canonical store.

## Impact

Existing domain/Jev adapter, sampling SQL, synthetic/disposable tests and runbook/OKF claims. No dependency, migration, scheduler, automatic capture or new evaluation framework. A small approved fresh-mail preview follows offline verification; task creation still requires a specific proposal approval.
